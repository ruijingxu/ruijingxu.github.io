# Ruijing Xu's Academic Homepage

Source for [ruijingxu.github.io](https://ruijingxu.github.io/), a personal
academic homepage focused on robotics and embodied AI.

The page layout is adapted from
[Jon Barron's academic website](https://github.com/jonbarron/jonbarron.github.io),
whose README permits cloning the code for personal use. All personal text,
media, and research content in this repository belong to Ruijing Xu.

## Updating the site

- Edit biography and research content in `index.html`.
- Store profile and project images in `images/`.
- Store the CV and other downloadable documents in `data/`.
- Run `.venv/bin/python -m unittest tests/test_site.py -v` before publishing.
